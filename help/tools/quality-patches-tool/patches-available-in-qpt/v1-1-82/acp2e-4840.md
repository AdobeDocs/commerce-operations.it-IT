# ACP2E-4840: la query prodotti GraphQL restituisce quantità null per i prodotti in magazzino nelle scorte di magazzino personalizzate

La patch ACP2E-4840 risolve il problema se il campo quantità nella query GraphQL dei prodotti restituisce null per i prodotti in magazzino e disponibili per la vendita su scorte di magazzino personalizzate. Questa patch è disponibile quando è installato [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82. L’ID della patch è ACP2E-4840. Tieni presente che questo problema è pianificato per essere risolto in Adobe Commerce 2.4.10.

## Prodotti e versioni interessati

**La patch è stata creata per la versione di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.8-p4

**Compatibile con le versioni di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>La patch potrebbe diventare applicabile ad altre versioni con le nuove versioni di [!DNL Quality Patches Tool]. Per verificare se la patch è compatibile con la versione di Adobe Commerce in uso, aggiornare il pacchetto `magento/quality-patches` alla versione più recente e verificare la compatibilità nella pagina [[!DNL Quality Patches Tool]: Cerca patch](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilizza l’ID patch come parola chiave di ricerca per individuare la patch.

## Problema

Il campo quantità nella query GraphQL dei prodotti restituisce null per i prodotti in magazzino disponibili per la vendita su scorte di magazzino personalizzate.

<u>Prerequisiti</u>:

MSI è abilitato.

<u>Passaggi da riprodurre</u>:

1. Crea una nuova origine.
1. Nella barra laterale di amministrazione, vai a **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Fare clic su **[!UICONTROL Add New Stock]**.
1. Espandere **[!UICONTROL Sales Channels]** e selezionare **[!UICONTROL Websites]** in cui le scorte sono disponibili.
1. Espandere **[!UICONTROL Sources]**, fare clic su **[!UICONTROL Assign Sources]**, selezionare l&#39;origine che si desidera assegnare e fare clic su **[!UICONTROL Done]**.
1. Nella barra laterale di amministrazione, vai a **[!UICONTROL Catalog]** > **[!UICONTROL Products]** e apri un prodotto esistente in modalità di modifica.
1. Nella sezione **[!UICONTROL Sources]**, assegnare l&#39;origine personalizzata, impostare **[!UICONTROL Source Item Status]** su **[!UICONTROL In Stock]**, immettere un valore diverso da zero per **[!UICONTROL Qty]** e salvare il prodotto.
1. Confermare in **[!UICONTROL Catalog]** > **[!UICONTROL Products]** che il prodotto mostri un **[!UICONTROL Salable Quantity]** diverso da zero per il sito Web assegnato al titolo personalizzato.
1. Eseguire la seguente query `products` [!DNL GraphQL] per lo SKU in base alla visualizzazione archivio assegnata al sito Web che utilizza lo stock personalizzato:

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Osserva la risposta:

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Risultati previsti</u>:

La risposta di GraphQL restituisce un valore di quantità non nullo per i prodotti che sono in magazzino e vendibili nel negozio/sito Web corrente.

<u>Risultati effettivi</u>:

La risposta di GraphQL restituisce `quantity = null` mentre `stock_status` = `IN_STOCK` per i prodotti in magazzino e vendibili nell&#39;amministratore quando lo store utilizza uno stock MSI personalizzato.
