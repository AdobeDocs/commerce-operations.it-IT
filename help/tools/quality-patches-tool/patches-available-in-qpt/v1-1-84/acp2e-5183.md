# ACP2E-5183: la distribuzione di contenuto statico non riesce in PHP 8.5 con `@magento_import`

La patch ACP2E-5183 risolve il problema se la distribuzione del contenuto statico non riesce in PHP 8.5 con l&#39;errore *L&#39;utilizzo di null come offset di array è obsoleto* quando un file del modulo `LESS` utilizza la direttiva `@magento_import`. Questa patch è disponibile quando è installato [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. L’ID della patch è ACP2E-5183. Tieni presente che questo problema è pianificato per essere risolto in Adobe Commerce 2.4.10.

## Prodotti e versioni interessati

**La patch è stata creata per la versione di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.9

**Compatibile con le versioni di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.4 - 2.4.9

>[!NOTE]
>
>La patch potrebbe diventare applicabile ad altre versioni con le nuove versioni di [!DNL Quality Patches Tool]. Per verificare se la patch è compatibile con la versione di Adobe Commerce in uso, aggiornare il pacchetto `magento/quality-patches` alla versione più recente e verificare la compatibilità nella pagina [[!DNL Quality Patches Tool]: Cerca patch](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=it). Utilizza l’ID patch come parola chiave di ricerca per individuare la patch.

## Problema

La distribuzione del contenuto statico non riesce in PHP 8.5 con l&#39;errore *L&#39;utilizzo di null come offset di array è obsoleto* quando un file modulo `LESS` utilizza la direttiva `@magento_import`.

<u>Prerequisiti</u>:

PHP 8.5 è installato.

<u>Passaggi da riprodurre</u>:

1. Abilita un modulo personalizzato che fornisce un file `email-inline.less` contenente uno stile personalizzato per il corpo dell&#39;e-mail e una direttiva `@magento_import`.
1. Rimuovi contenuto statico e file generati:

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. Eseguire l&#39;implementazione dei contenuti statici utilizzando la strategia compatta:

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>Risultati previsti</u>:

La distribuzione del contenuto statico viene completata e genera il file CSS compilato per il file `LESS` fornito dal modulo.

<u>Risultati effettivi</u>:

La distribuzione del contenuto statico viene interrotta durante la compilazione del file `email-inline.less` e dei report forniti dal modulo:

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
