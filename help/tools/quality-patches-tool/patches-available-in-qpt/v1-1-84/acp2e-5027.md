# ACP2E-5027: gli indicizzatori non vengono completati quando il blocco dell&#39;applicazione utilizza il provider di blocco file

La patch ACP2E-5027 risolve il problema per cui gli indicizzatori non finiscono mai perché continuano a tentare di acquisire il proprio blocco quando `use_application_lock` è abilitato e il provider del blocco file è configurato. Questa patch è disponibile quando è installato [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. L’ID della patch è ACP2E-5027. Questo problema è pianificato per essere risolto in Adobe Commerce 2.4.10.

## Prodotti e versioni interessati

**La patch è stata creata per la versione di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.9

**Compatibile con le versioni di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) 2.4.4 - 2.4.9

>[!NOTE]
>
>La patch potrebbe diventare applicabile ad altre versioni con le nuove versioni di [!DNL Quality Patches Tool]. Per verificare se la patch è compatibile con la versione di Adobe Commerce in uso, aggiornare il pacchetto `magento/quality-patches` alla versione più recente e verificare la compatibilità nella pagina [[!DNL Quality Patches Tool]: Cerca patch](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilizza l’ID patch come parola chiave di ricerca per individuare la patch.

## Problema

Gli indicizzatori non finiscono mai perché continuano a tentare di acquisire il proprio blocco quando `use_application_lock` è abilitato e il provider del blocco file è configurato.

<u>Passaggi da riprodurre</u>:

1. In `app/etc/env.php`, abilitare il blocco dell&#39;applicazione per gli indicizzatori e impostare il provider del blocco su file:

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. Esegui l&#39;indicizzatore `catalog_product_category`:

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>Risultati previsti</u>:

Reindicizzazione di `catalog_product_category` completata.

<u>Risultati effettivi</u>:

La reindicizzazione non viene mai completata.
