# ACP2E-5017: la query del ruolo cliente GraphQL non riesce per i clienti senza un’azienda

La patch ACP2E-5017 risolve il problema per cui il campo `role` della query GraphQL `customer` restituisce *Errore interno del server* per un cliente non assegnato a una società. Questa patch è disponibile quando è installato [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84. L’ID della patch è ACP2E-5017. Questo problema è pianificato per essere risolto in Adobe Commerce B2B 1.5.4.

## Prodotti e versioni interessati

**La patch è stata creata per la versione di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) B2B 1.5.3

**Compatibile con le versioni di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>La patch potrebbe diventare applicabile ad altre versioni con le nuove versioni di [!DNL Quality Patches Tool]. Per verificare se la patch è compatibile con la versione di Adobe Commerce in uso, aggiornare il pacchetto `magento/quality-patches` alla versione più recente e verificare la compatibilità nella pagina [[!DNL Quality Patches Tool]: Cerca patch](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilizza l’ID patch come parola chiave di ricerca per individuare la patch.

## Problema

Il campo `role` della query di GraphQL `customer` restituisce *Errore interno del server* per un cliente non assegnato a un&#39;azienda.

<u>Prerequisiti</u>:

B2B è installato.

<u>Passaggi da riprodurre</u>:

1. In Amministrazione, passare a **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**, impostare **[!UICONTROL Enable Company]** su *[!UICONTROL Yes]* e fare clic su **[!UICONTROL Save Config]**.
1. Creare un conto cliente non assegnato a una società.
1. Invia la seguente query GraphQL utilizzando un token cliente valido:

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>Risultati previsti</u>:

La query restituisce i dati del cliente con `role` impostato su *null*, senza errori.

<u>Risultati effettivi</u>:

La query restituisce *Errore interno del server*.
