# ACP2E-4639: tipo di voci dell’elenco delle richieste di acquisto errato nello schema di Adobe Commerce GraphQL

La patch ACP2E-4639 risolve il problema relativo all&#39;errata ortografia del tipo di elementi dell&#39;elenco richieste nello schema di GraphQL. Il nuovo campo `requisition_list_items` restituisce il tipo `RequisitionListItems` digitato correttamente, mentre il campo `items` precedente e il tipo `RequistionListItems` rimangono disponibili ma sono obsoleti. Questa patch è disponibile quando è installato [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83. L’ID della patch è ACP2E-4639. Questo problema è stato risolto in Adobe Commerce B2B 1.5.3.

## Prodotti e versioni interessati

**La patch è stata creata per la versione di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) B2B 1.5.2 - p1

**Compatibile con le versioni di Adobe Commerce:**

* Adobe Commerce (tutti i metodi di implementazione) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>La patch potrebbe diventare applicabile ad altre versioni con le nuove versioni di [!DNL Quality Patches Tool]. Per verificare se la patch è compatibile con la versione di Adobe Commerce in uso, aggiornare il pacchetto `magento/quality-patches` alla versione più recente e verificare la compatibilità nella pagina [[!DNL Quality Patches Tool]: Cerca patch](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilizza l’ID patch come parola chiave di ricerca per individuare la patch.

## Problema

Il tipo di elementi dell&#39;elenco richieste di acquisto è stato digitato in modo errato come `RequistionListItems` nello schema di GraphQL. Il campo `items` precedente e il tipo `RequistionListItems` rimangono disponibili ma sono obsoleti.

<u>Prerequisiti</u>:

Adobe Commerce con l’estensione B2B.

<u>Passaggi da riprodurre</u>:

1. Invia la seguente query introspettiva GraphQL:

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. Nella risposta, controllare il tipo restituito dal campo `items`.

<u>Risultati previsti</u>:

1. Il campo `requisition_list_items` restituisce il tipo `RequisitionListItems` digitato correttamente.
1. Il campo `items` e il tipo `RequistionListItems` rimangono disponibili e sono contrassegnati come obsoleti.

<u>Risultati effettivi</u>:

Il campo `items` restituisce il tipo `RequistionListItems` errato e nessun campo restituisce il tipo `RequisitionListItems` digitato correttamente.
